# Reference

Every concept is defined on exactly one page here. Everything else links to it.

A test arranges resources, acts, and asserts. Those three pages carry most of the surface; the
other five describe what surrounds them.

## The three verbs

[Arrange](arrange.md) is the longest of them and the one the design turns on. It owns resource,
lineage, asking for one, factory, system, recognition, when it is not there, scope, variation and
adapter. [Act](act.md) owns action, running something, using an interface, phrase, a step you write
and naming a result. [Assert](assert.md) owns claim, marker, interface claim and a claim you
register.

## Around them

Underneath sits [the ground](the-ground.md), which owns environment, may be changed, and every key
`atf.yaml` takes. Above it, [the record](the-record.md) owns run, outcome, verdict, history and
report.

## Surfaces

The same model, met three ways. Each concept above says what it looks like in each.

[The command](the-command.md) lists every subcommand, flag and exit code. [The
editor](the-editor.md) says what each view shows and what it reads. [Extending
ATF](extending-atf.md) is where an adapter, a claim, a marker, a report format or a check gets
registered.

For a one-sentence definition of any term, see the [glossary](../orientation/glossary.md). For how
the concepts relate, [the model](../orientation/the-model.md).
