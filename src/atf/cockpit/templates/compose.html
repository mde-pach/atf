How a scenario is put together
Given
Names a resource the behaviour needs. You never write these — ATF creates whatever they name, dependencies first, and hands each record to your own steps.
When
The action under test. Yours, defined with @when in a steps/test_*.py module.
Then
What must be true afterwards. Yours too, defined with @then.
Afterwards
pytest collects one test per scenario, but only once a steps/test_*.py module binds the feature with scenarios(…). This page tells you if that is still missing. {% if docs() %}Life of a run{% endif %}
